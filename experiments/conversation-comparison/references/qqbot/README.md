4. [SOURCE.json](SOURCE.json)：原始 URL、提交、源文件 SHA-256／Git blob、逐行来源、摘录 SHA-256、许可声明位置。

行号按下载的 raw 原文件计算，不能拿压缩空行后的网页阅读器行号替代。摘录保留原始 UTF-8、行末与标点，不添加来源标题到原文文件内部。

## 为什么选这 7 行

下表是本项目的编辑说明，不属于上游提示词。原文见候选文件。

| 原文件行 | 可参考的点 | 适用边界 |
| --- | --- | --- |
| 31 | 直接接当前消息，少作回答／分析预告 | 闲聊场景；不要求取消必要的确认或澄清 |
| 34 | 不连续堆同一口癖 | 原行中的直播口癖是反例，不是建议角色采用的词表 |
| 37 | 说完就收，不加客服式续问招揽 | 对方有问题仍正常回应，不等于刻意冷淡 |
| 213 | 不用分析式开场包装普通接话 | 不据此禁止认真解释复杂问题 |
| 217 | 自然表达不知道或没印象 | 这几个说法并非每次等义；不能有意隐瞒身份，或在没有检索能力时假称会查资料 |
| 219 | 用普通的肯定表达 | 不要求每轮都先赞同，也不要求反复使用“确实”等固定口头禅 |
| 249 | 对比正式动词与日常说法 | “看看”有时不等于完整分析，不能用全局替换损失意思 |

这份候选不能单独定义女性、年龄、亲密关系或个人性格，也没有证明它能改善当前模型的实际表现。

## 未直接采用的部分

- L212 一并禁止“请问”等礼貌词，属于特定群聊口吻，不能扩大到陌生人、服务场景或正式交流。
- L33、L38、L214、L216、L250–L253 带游戏／直播语境。L216 的反问及 L218 的“你想多了”可能带挑衅或轻视；本次没有为让角色更口语而引入这种默认态度。
- L215 以及 L218 的整行包含可参考与不适配表达；为保持完整行原样，本轮没有拆改后伪称上游原文模块。
- L220 不能把精确数字改成随意估计；L221 不是等义替换表。“此前”不一定是“刚才”，“目前／当下”指现在，“一会儿”通常指未来。具体事实和时态优先。
- L225、L234、L240 的“绝对不能”是上游角色的风格限制，不是通用中文禁词规范。比如“的情况下”并非只会出现在 AI 回复中。
- 游戏口癖、选手／主播梗、礼物互动、切片与事件语录未提取。这些也不能因项目声明 MIT 就被视作已确认全部第三方权利。
