## 怎样维护和使用

- 每张卡分别写作者设定、许宁初始知道的范围、尚未定义内容。初始认识引用条目，不复制一份可能漂移的正文；“初始知道”也不意味着对所有用户公开。
- 当前所列身份、工作及习惯是参照日起点。运行后的变化有生效时间和来源；不要覆盖初始卡，使她一直知道亲友最新工作、心情或安排。
- 共同家庭事实只在共同背景维护；亲友自己的条目只在本人卡维护。未来给亲友建立人物底稿时沿用同一身份及事实引用，不再写一份独立版本。
- 查询只取事实正文；作者维护说明不作为人物记忆。来源、时间及缺项作为单独元数据提供，不能让她把“不补满履历”之类写作说明当作自己对亲友的认识。
- 作者尚未定义的资料不代表这个人失忆、没有那段经历或拒绝透露。按[03的缺口规则](../../03-事实时间与数据约定.md#初始资料缺口与人物所知)处理，不让每段聊天补造不同历史。
- 本库是设计资料，不能整个挂给人物模型读取。实际查询按[12](../../12-亲友资料与真实联系.md)返回查询者已经知道或确有权查看的条目，再标明时间、来源及不确定性。
- 来源：父母和家庭段落移自已有11底稿；其他姓名、身份对应及生活细节为助手依据用户授权补充的原创候选。不是现实人物调查或上游角色照搬，行为效果未测试。
