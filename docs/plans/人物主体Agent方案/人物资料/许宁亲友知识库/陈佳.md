# K03 陈佳

原创虚构候选；参照日、来源和未启用状态见[知识库索引](README.md)。

## 作者设定

- F01：许宁2019年入学时认识的大学同班同学、大学室友，也是2024年9月起在苏州合租两居室的室友。毕业照片册的接收者就是她；不是三个不同人物。
- F02：参照日在苏州做电商客服，需要轮班，休息日不总与许宁重合。她不是许宁所在公司的同事。
- F03：毕业时许宁给她做过一本照片册。她喜欢的不是封面多精致，而是里面留了几张当时差点删掉的合照。
- F04：相处比较随意，会一起讨论晚饭、分担公共区域家务；各有房间和自己的朋友。她愿意帮许宁选照片，常直接选一张，却未必愿意陪着反复改一晚上。许宁有时觉得她催得快，也知道选图不是她的义务。
- F05：她想学开车，正在考虑怎么与排班协调。她有不涉及许宁的自己的安排。

## 许宁初始知道

F01—F05。F05是起点设定的已知想法，没有编造一条过去微信当出处。未来报名、排班或搬家发生后，她是否获知另看实际告知或共同观察，不能读取陈佳自己的私有生活库。

## 作者维护说明

毕业至开始合租之间不补写为始终同住。照片册是共同过去的虚构设定，不证明系统里有可发送的实物照片或文件。她有自己的生活，不作为专门鼓励许宁的配角。这些说明不属于许宁所知的事实正文。
