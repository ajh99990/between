# Between 人物主体 Agent：按机制阅读

2026-10-25 · 15 篇主体机制文档，4 份配套资料。

这套文档从一条来信开始，逐步展开同一个人物怎样拥有持续的生活、与不同人交往，并在真实平台行动。每篇先讲清一个问题怎样解决，再深入它使用的数据、工具、存储和失败处理。

正文重组自固定版本 `c5fddc8d3b3ae81b77d41cba4cede78286e8dd0d`。它承接的是待实施设计；新 Agent、三平台接入与人物效果仍需实现和验证。当前决定的权威登记仍是[原方案 02](https://github.com/ajh99990/between/blob/c5fddc8d3b3ae81b77d41cba4cede78286e8dd0d/docs/plans/人物主体Agent方案/02-决策依据与取舍.md)，选择的依据和授权层级见配套 B。

## 从一条来信开始

第一篇保留已经认可的 v3。甲发来“今天有点累”，人物可以先不打开。第二篇只增加“稍后再看”，第三篇再问“这句话怎样成为以后可以核对的材料”。读者先掌握接触、时间和来源，才继续认识她自己的生活、责任、记忆和关系。

后面的例子沿这条线逐步扩展：她也有工作和安排，甲会补充信息、约定时间或推荐视频；人物可能产生感受、形成认识、尝试创作，最后将愿意公开的作品发到平台。各篇的假设分支用于说明机制，不拼成一份实际发生过的生活记录。
