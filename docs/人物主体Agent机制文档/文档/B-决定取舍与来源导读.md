## 这个人物的目标

目标是同一份持续生活、与不同人分别交往、能在真实平台行动的虚拟人物。内容候选以大陆普通成年女性为起点，18—28岁是候选范围，兼职模特是偏好背景；具体年龄、城市及职业经历仍待确定。自然性先体现于普通措辞、对事物的态度及亲近与边界，并不由年龄性别标签或戏剧化身世保证。

生活、时间、未完成事项和平台反馈都能提供行动机会；模型可以结束一次进程，持久的安排和事实继续存在。[原01：目标与连续性](https://github.com/ajh99990/between/blob/c5fddc8d3b3ae81b77d41cba4cede78286e8dd0d/docs/plans/人物主体Agent方案/01-总体设计与贯穿案例.md#L5-L11)。

用户认可并要求保留的研究起点原文如下：

> 接下来研究人物行为，应先问：她正在做什么、在意什么、注意到了什么、愿意投入多少，再看这条消息怎样影响她。她也可以主动改变安排、处理自己的事情，或者暂时什么都不做。这样才能讨论一个持续生活的人，而不只是每轮怎样接话。

完整十条愿望在[A-用户愿望原文](A-用户愿望原文.md)，保持原字节；愿望中的“尚未确定”保留当时语境，后来的采用状态以下表及正式02为准。

## 人物概念框架的证据位置

六类人物信息、独立环境、局部变化和有限察觉来自已认可的[人物行为变化框架](https://github.com/ajh99990/between/blob/c5fddc8d3b3ae81b77d41cba4cede78286e8dd0d/docs/plans/人物行为变化框架-v0.1.md)。这是一种可检查的设计综合。各研究帮助提出区别，未共同验证一套完整心理模型，也没有给出本项目的恢复参数或大陆年轻女性统一话术。

|研究线|本方案借用的认识|原资料的限制|
|---|---|---|
|Fleeson状态分布、CAPS|同一个人会随处境变化，个人特点也可体现为有条件的反应|经验采样与理论有不同证据性质，不能决定每句话的表达|
|McAdams/Pals整合人格|底稿还包括目标、应对方式、经历与文化背景|理论框架，不由年龄性别推出统一人格|
|Scherer、Gross、EMA|发生、察觉、主观评价、感受、倾向、实际行动可以区分并反馈|理论间时序有分歧；不对应固定串行脑区，EMA示意不等于心理实证|
|Carver/Scheier、Wood/Rünger|自己的关切、进展与习惯参与选择，普通回应不必每轮深度分析|理论及综述不覆盖所有情绪原因，也不提供固定台词|
|Laurenceau等亲近日记|披露、被理解与当次亲近相关|69/89名美国大学生、单方报告与相关性限制，不证明多关心必增亲密|
|Rempel等信任研究|不同方面的信任可以区分|47对加拿大伴侣，不等于关系必经升级阶段|
|Schweitzer等信任修复|承诺、道歉、后续行为的证据不同|262人的七轮金钱博弈，不支持“道歉无用”或“永久不能修复”|
|Verduyn等时长综述|重要性、再现与回想可影响持续，事情结束不等于感受立刻结束|未给本项目恢复常数|
|Gross/Barrett理论比较|情绪产生和调节的划分存在理论差异|概念区分不应冒称已确定的脑机制|

完整作者、题名、获取范围和原始文献链接保留在[框架参考文献](https://github.com/ajh99990/between/blob/c5fddc8d3b3ae81b77d41cba4cede78286e8dd0d/docs/plans/人物行为变化框架-v0.1.md#L299-L313)。框架中的五组案例、17项成对检查是自拟概念材料；本套C保留它们的检验用途，不把它们标为已发生的模型行为。
