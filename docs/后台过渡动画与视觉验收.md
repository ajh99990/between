## 设计判断与实现

| 场景 | 最终行为 | 时长 |
| --- | --- | --- |
| 弹窗 | 独立玻璃材质层、内容、边框与阴影颜色同步出现/退出；不移动或降低玻璃祖先的不透明度 | 进入 210ms / 退出 150ms |
| 下拉菜单 | 自身拥有 backdrop-filter，且没有后代玻璃；整块菜单淡入淡出，不缩放、不平移 | 170ms / 120ms |
| 页面、角色、字段、世界书及条目切换 | 新内容立即生效，正文仅从 0.84 恢复到 1；不保留旧私有正文叠层 | 120ms |
| 导航、列表、目录、表格选中/悬停 | 背景、边框和文字颜色过渡；不扩大命中区域 | 120ms |
| 保存/刷新 | 原按钮宽度保持，忙碌时显示居中旋转反馈，结束后通知进入/退出；不人为延迟保存 | 按钮 120ms；通知 180ms / 140ms |

主要缓出曲线为 `cubic-bezier(.23,1,.32,1)`。减少动态时去除位移，浮层仅短暂透明度变化；键盘打开和关闭浮层立即完成。显式正文定位滚动也遵守减少动态偏好。移动端原有导航抽屉保留。

主动排除逐行入场、交错弹跳、滚动驱动长文、正文缩放/模糊、自动高度测量和输入时重复动画。输入内容、搜索词、保存版本不作为长文动画 identity；只使用文档 ID、读写模式、字段名或条目 UID。快速重复切换不从头闪烁。

React 使用 `MotionConfig`、`motion.main`、`AnimatePresence` 和 `animate`。独立 DOM 组件使用可取消的 Web Animations API，保持原受控接口及焦点栈。退出阶段保留视觉内容但设为 inert、停止响应输入；退出完成后隐藏并恢复触发器焦点。权限变化使用立即关闭，不播放敏感浮层退出动画。鉴权过期时草稿按原契约保留并隐藏，不能将此描述为已从 DOM 清除所有私有内容。

关键文件：`src/motion.tsx`、`src/motion.css`、`src/reader-motion.tsx`、`src/ui.tsx`、`public/design/surface-motion.js`，以及现有 Dialog/Select 适配层。边框和阴影颜色过渡会有短时绘制成本；没有宣称全部动画仅走 GPU。

## 实际发现与修正

| 问题 | 修正与复查 |
| --- | --- |
| 延迟关闭期间，浮层还可能接受点击或重新聚焦 | 退出时 inert、pointer-events 与焦点栈关闭状态联动；重开可取消旧退出；销毁和鉴权关闭立即完成。生命周期测试覆盖中断与清理。 |
| 业务状态先清空确认内容，出现空弹窗退出 | React Dialog 冻结最后一次打开时的呈现快照，直到退出结束；业务状态仍立即生效。登录退出直接卸载，过期立即隐藏。 |
| 只淡出文字后，短暂留下空玻璃、菜单底板或细边框 | 弹窗独立玻璃层与内容一起淡出，并同步边框/阴影颜色；菜单自身整块淡出。最终正常速度录屏的退出和重开帧已复查。 |
| 覆盖视口与浏览器缩放组合下，CDP 帧出现菜单外硬边模糊块 | 与默认尺寸普通截图对照，未在页面稳定截图复现；改用当前页面实际像素尺寸录制。最终 1440×900 和默认尺寸录屏无此伪影。不将采样问题伪称为已确认的产品 CSS 缺陷。 |

## 正常速度操作与像素验收

主 agent 在 Codex 浏览器实际点击、键入、切换、保存及关闭；查看了截图和连续过渡帧。独立 agent 另外复核代码和录制帧，没有把其帧审查称为它亲自操作浏览器。没有修改应用动画倍率或降低播放速度。

本机证据位于忽略目录 `artifacts/browser/admin/motion-20261016-222059/`：

- `弹窗与菜单-正常速度.mp4`：最终构建，1440×900，240 帧，原始时间轴约 9.97 秒；菜单选择/关闭、弹窗关闭/重开。
- `长文编辑与保存-正常速度.mp4`：1138×818，314 帧，约 9.93 秒；世界书条目切换、中文输入、切回草稿、保存成功通知。
- 两个视频旁的 JSON 及各自原始 `recording.json` 保留时间戳和捕获声明；编码不采用固定 FPS 加速。
- `desktop-surfaces-final/`、`surfaces-final-accepted/`：最终浮层版本的桌面与窄视口连续帧；先前失败/旧版捕获仅为排障记录，未计作最终通过证据。
- `menu-desktop-final.png`、`worldbook-save-success.png`、`save-error.jpg`、`menu-390.png`、`worldbook-390-reduced.png`：稳定材质、长文、失败与窄屏状态。

在真实接口调用前临时模拟离线，观察“未保存、草稿仍在”；恢复连接后保存成功，配置版本从 v2 到 v3。世界书中文输入后保留焦点与选区，切换条目再切回仍有修改，成功保存到 v4。为看清忙碌反馈，仅在隔离页将网络延迟临时设为 600ms，随后恢复；动画仍是正常 1×，产品代码没有加入假等待。

减少动态模拟下，第一次 Esc 仅收起下拉，第二次关闭弹窗并返回外观触发器。界面实际检查桌面、750 与 390 目标宽度，以及默认浏览器尺寸；自动化覆盖同样三个响应式目标。
