## 技术来源与当前状态

采用完整 Ant Design Pro 的 Umi Max 框架结构及布局、路由、模型、权限、请求插件。官方模板来源：<https://github.com/ant-design/ant-design-pro>，固定提交 `4ee65150b7318af933e56267d257bd9fe644fbd4`，模板版本 6.0.3。其 MIT 许可证原文保留于 `sillytavern/admin/LICENSE`。

锁文件实际版本：Umi Max 4.7.3、React 19.2.7、Ant Design 6.6.0、ProComponents 3.1.14-2、TypeScript 7.0.2、Tailwind CSS 4.3.3。使用仓库要求的 Node 24。

完整官方 Pro 使用 Umi；Vite 是另一套构建方案，不能把 Umi 模板当作 Vite 项目运行。当前草稿没有引入 Vite。官方模板的 utoopack 配置未沿用，当前实际走 Umi 的 Webpack/esbuild 构建链，存在下述阻塞，待云端核对选择。没有通过关闭错误检查规避失败。

Tailwind 用于自定义布局和阅读样式，使用 CSS layer，与 Ant Design 组件样式配合，不引入 Tailwind Preflight。模板演示页面、演示接口和假数据没有迁入业务页面。完整模板依赖尚未整理，锁文件根名称仍是 `ant-design-pro`；存在未使用的 `Placeholder.tsx`，都需后续收尾。
