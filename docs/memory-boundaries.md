# 记忆候选的已实现边界

当前 schema6 开发候选，最终状态以本轮独立验收为准。真实模型调用为 0。

## 用户体验与语义范围

记忆默认关闭；开启仍是自然聊天，不要求每条信息使用保存命令，也不增加逐条确认界面。当前实现能验证来源、引文、权限、状态、版本及预算，尚不能证明普通偏好的自动识别、普遍改述召回或自然语言纠错质量。内部 `needs_review` 不等于已知事实，也不能据此承诺未来会记得。

生产数据没有天气/颜色等领域枚举。`user_report` 表示用户说过的内容，不是外部核实事实。未知的结构化 subject/object/condition 不猜测。明确完整保存请求和精确旧/新更正格式是确定性准入子集，不定义整个产品只能接受命令。

## 选择与来源

控制、人物与当前输入优先。常驻上限 2 条，词面/短词补充和可选候选 ranker 共用总上限 3 条；字节预算不是 tokenizer 验证。默认未接语义 ranker。候选只提出 ID，最终正文、来源修订、状态、有效期与处理游标重新核对权威数据库。

关闭记忆禁止读取长期记忆、提议和 ranker；重开可用仍有效的此前存量，不补提关闭期间的内容。失效/修订不匹配来源不能由近期模型历史或长期保留路径重新注入。真实聊天 UI 历史与模型上下文投影分开。

## 写入与回执

`remember_user_report` 保持一项工具，使用严格模式区分原话、常驻、提议和更正/变化。模型无权建立身份、授予记忆许可或更改控制。更正带目标修订、当前状态版本、当前来源证据和幂等 ID；未经支持的语义不会猜测提交。

授权、同轮 context、epoch、来源真值先于幂等回执读取；目标状态和 CAS 在首次应用中校验。历史成功回执不代表记录现在仍有效；重试不能再次执行副作用或复活旧记录。来源/记录修订和替代关系保留必要无正文状态。

## 保留与恢复

普通来源/聊天受原有 30 天保留；需要继续支撑有效记忆的证据仅保留必要精确片段。纠错不能将包含旧错误的整个指令当永久替代证据。候选过期以绝对时间判断，在线维护、备份前及下次启动清理；不声称停机期间定时物理擦除。缓存有界且不保存明文当前查询，关闭/结束/删除/close 清理。

schema5 和更旧库拒绝自动迁移。备份、封存恢复及删除使用相同版本和来源规则；过期但未清理的待审正文会让只读离线 checkpoint 明确拒绝，而非改变封存原库。平台来源编辑/撤回接入 API、完整语义纠错、多规模性能和真实模型效果仍是后续验收项。
