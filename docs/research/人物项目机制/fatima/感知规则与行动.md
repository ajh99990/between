## 一次事件如何产生后果

假设她正在赶报表，甲又来催。这套系统不会直接读中文聊天、自动猜完所有含义。宿主先把发生的事转换成符号事件与观察者，交给 RolePlayCharacter.Perceive。角色有知识库、目标和自传记录；评价模块依据这些材料生成情绪。随后 Decide 查询行为规则，返回动作候选，再由宿主执行。[^fm-map-rpc][^fm-map-decision]

```text
# 概念伪代码：符号形状由宿主的领域定义
host receives interruption
character.Perceive(event, observer)
    invalidate social-importance cache
    handle action start/end if applicable
    appraise event using beliefs and goals
candidates = character.Decide()
host executes chosen candidate
host reports actual result through Perceive again
host calls Update() to advance simulation time
```

这条主线能贯穿多模块，但不表示下载库后已有生活日程、中文聊天理解或平台工具。尤其 WorldModel 返回的是模拟后果，不是执行真实操作的回执。[^fm-map-world]

| 编号／机制 | 实际链路及边界 |
| --- | --- |
| F01 感知、信念与人物视角 | 宿主调用 Perceive，将符号事件与观察者交给评价模块，记录经历并更新相应信念；不自动从自由中文或真实平台抓取事件。角色另有信念值及确定性的读写接口。[^fm-map-rpc] |
| F02 目标与事件评价 | 目标保留 likelihood/significance，评价规则依据知识与事件生成评价变量，再推导情绪。目标存储不等于自动规划日程、执行任务。[^fm-map-appraise] |
| F04 时钟与衰减 | 宿主调用 Update 增加 tick，再推进情绪与心境；不能把 tick 默认当一分钟，也不能仅按聊天次数当现实时间。[^fm-map-rpc] |
| F05 由信念与情绪选择动作 | EmotionalDecisionMaking 匹配行动规则与条件，生成候选动作；RolePlayCharacter 将最大 utility 候选置前，同分随机顺序，已在执行动作可继续返回 committed action。执行动作仍由宿主负责。[^fm-map-decision] |
| F06 社会重要性 | SocialImportance 依据针对对象和视角的归因条件求值并缓存，感知事件会使缓存失效；通过知识库动态属性影响条件查询。它不是已训练好的通用亲密度。[^fm-map-social] |
| F07 社交交换意愿与身份 | CommeillFaut 将社交动作、阶段、对象等转换成 Volition 查询；角色可激活身份并暴露身份显著性。要配置相应规则才有行为后果，不是从一句话自动识别人际潜规则。[^fm-map-social] |
| F08 世界事件后果 | WorldModel 匹配事件模板与优先级，返回属性变化及观察者；宿主据此处理模拟后果。返回模拟效果不等于已经改变真实世界。[^fm-map-world] |
| F09 对话状态与场景创作 | IntegratedAuthoringTool 保存人物、世界、对话动作，按当前/下一状态、meaning/style 查询候选话语；资产可序列化。属于作者配置的场景结构，不是大模型自行写出普通人的语言。[^fm-map-author] |
| F10 可检查与可修改的内部记录 | 角色提供事件读写/遗忘、信念读写、活跃情绪查询/移除、序列化等接口；这些是管理与宿主能力，不能自动解释为人物心理自我修复。[^fm-map-rpc] |

## 什么数据令规则有上下文

角色保存的目标有 likelihood 和 significance；知识查询还会读取 Mood、Goal、Tick、最强情绪及强度、身份显著性、自传事件等动态属性。行为规则因此可以依赖“目标是否受阻、她此刻怎样感受、对方的重要性”，而不是每个事件固定一句台词。它仍要求作者配置有效的知识、评价与行为规则。[^fm-map-rpc]

SocialImportance 对目标与视角计算归因条件之和并缓存；新的感知使缓存失效。CommeillFaut 按社交动作、阶段、对象等提供 Volition 查询。这些都是可配置的结构，不是预训练出来的大陆青年社交经验。把规则值命名为亲密度，不能证明它会产生自然语言。[^fm-map-social]

Decide 将最大 utility 的候选放前，同分随机；若已有持续动作，可能返回 committed action。它并不是一定替宿主执行这项行动，也不是模型驱动的自由规划器。我们可以只研究其评价和情绪连续性，不必连同原行为选择一起采用。[^fm-map-decision]

## 创作、检查与修正

IntegratedAuthoringTool 维护人物、对话状态及候选话语；按当前/下一状态和 meaning/style 查询。角色还可读写信念、查询和移除情绪、遗忘事件、序列化。是作者/宿主的调试控制，不应解释为人物自己会心理治疗或自动修复矛盾。[^fm-map-author][^fm-map-rpc]
