# 独立套餐兼容后端

当前实现由管理员管理一份独立 Between 授权与额度；用户/角色/会话仍分别组装上下文并隔离。普通应用入口默认关闭套餐，可在后台「模型与提示词」启用。`start:local` 在应用数据尚无 `settings.json` 的首次初始化时会通过管理接口启用套餐，之后沿用已保存设置。默认模型 `gpt-6.1-sol`，思考档位 `medium`，可选 `high`。

## 本机常驻入口

从仓库根 `npm ci`、`npm run build` 后，已配置独立授权的操作者可执行 `npm run start:local`。启动器是 `apps/server/local-start.mjs`，默认根为 macOS `~/Library/Application Support/Between`：

| 路径/入口 | 用途 |
| --- | --- |
| `siwc/between.json` | 已有独立 Between 授权；只由凭据模块读取，不复制或回显 |
| `app-data` | 应用配置、身份索引和引擎聊天数据 |
| `runtime/status.json` | 本次 PID、启动状态与健康检查；不含口令或 token |
| `runtime/admin-password.txt` | owner-only 管理员口令，不打印 |
| `127.0.0.1:8787` | 聊天与 `/admin` |
| `127.0.0.1:8766` | 需要本地密钥的套餐兼容服务 |

`BETWEEN_LOCAL_ROOT` 只改变 `app-data` 与 `runtime` 所在的运行根，不改变默认授权路径 `~/Library/Application Support/Between/siwc/between.json`。使用另一份专用授权时，须同时设置 `BETWEEN_PLAN_CREDENTIALS` 为仓库外已有凭据的绝对路径；不能仅改变运行根就认定授权已经隔离。现存端口或所有权锁会拒绝启动，不能删除用户锁来抢占。启动器脱离终端持续运行；只向核验过的本次 PID 发送 SIGTERM 停止，退出释放应用和凭据锁。启动检查会用本地管理员口令登录管理接口、读取状态，首次初始化时保存套餐设置，检查页面后退出；不执行 OAuth 登录、模型发现或推理。上述行为可在 `apps/server/local-start.mjs` 核对。

普通 `npm start` 使用 Chat Completions 或可信宿主提供的 `BETWEEN_PLAN_SERVICE_URL` / `BETWEEN_PLAN_LOCAL_KEY`，仍须管理员明确启用套餐。兼容服务独立命令为 `node apps/server/plan-service-main.mjs --enable-plan-service`，需 `BETWEEN_PLAN_CREDENTIALS`、至少 24 字符 `BETWEEN_PLAN_LOCAL_KEY`，可用 `BETWEEN_PLAN_PORT` 选择回环端口。没有自动收费 API 回退。

## 授权与协议边界

已实现独立 OAuth helper、state/nonce/PKCE、签名与身份校验、单次回调、刷新 coalescing、终止错误与重新授权状态。CLI 入口均在 `apps/server/plan-auth.mjs`，`login` 需要 `--consent`、`logout`/`import` 需要 `--confirm`；每次操作明确指定仓库外专用绝对路径。真实登录、导入、退出或真实模型测试需要相应任务授权，不能因阅读本手册自动执行。不得读取或搬用 Codex、灵光或其他应用授权。

文件/目录须 owner-only，拒绝符号链接、硬链接、不安全权限及仓库内路径；同一文件只允许一个持有进程。崩溃后核实旧进程再处理残留锁。这不是多机器分布式锁，也不是对同一 OS 用户恶意替换目录的完整防御。

兼容服务固定发送 Responses 流：`store:false`，不带 `previous_response_id`；每轮由本机重新构造完整预算内文本上下文。实际复用的 `adaptRequest` / `ResponsesFrames` 在 `apps/server/lingguang`；保留 [来源与许可说明](../apps/server/lingguang/SOURCE.zh-CN.md)。system 原位转 developer，温度和输出上限等字段按既有适配删除；本地输出预算不代表远端强制输出上限。只接受文本，不发送工具或媒体。

只有 completed 且存在文本才提交，incomplete/断流/取消/断开回滚。明确额度上限暂停整个共享后端，管理员检查后恢复；常规429、401、临时服务失败与终止刷新状态分别处理。health 不刷新、不推理、不返回 token。错误原文不回传浏览器。

## 验证方式与边界

`npm run test:plan` 使用内存签名、假授权端点、模拟 Responses 流验证协议/刷新/档位与隔离；`npm run test:local` 验证合成授权下启动、HTTP、重启、端口冲突和清理。浏览器 OAuth helper 回归也使用合成端点，不能称真实授权成功。

离线测试不验证真实账户授权、账户模型目录或多人远程托管资格。历史真实文本实验见 [提示词对比记录](records/核心提示词对比与聊天记录验收.md)；它们仍未证明模型自然度或多人托管适用性。Langfuse 未接入。不能把套餐设置已保存或模型列表可用当成真实推理通过。
