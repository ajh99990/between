# 共享组件库与本轮验收

本轮在现有 monorepo 中建立私有 `@between/ui`，以 Base UI 提供交互基础，将后台通用控件、字体、图标、玻璃、背景和浮层动画归入同一来源。`apps/admin` 已迁移到共享组件，继续持有真实业务接口、权限、草稿和保存规则。用户聊天界面没有随组件包建设重写。

本报告记录 2026-10-18 本轮迁移的源码、自动化与实际浏览器证据。它与旧版后台重写、动画和产品内容报告分开；历史截图和历史测试数字不能证明当前组件迁移。当前自动化、实际操作、截图目视及正常 1× 录屏复验在本次范围内通过；最后 Git 提交与远端核验仍独立记录，不能把视觉验收等同于合并或部署。

## 结构与职责

| 位置 | 当前职责 | 不应放入的内容 |
| --- | --- | --- |
| `packages/ui/src/components` | 操作、表单、选择、浮层、反馈、表格和分页的默认外观与组合接口 | 业务 API、管理员身份、世界书字段规则、产品存储 |
| `packages/ui/src/materials` | 自包含玻璃、高光、字体资源和程序背景的 React 适配及销毁 | 另一业务仓库的访问或运行依赖 |
| `packages/ui/src/motion` | 浮层呈现生命周期、进入、退出、中断和清理 | 延迟业务成功、清空调用方草稿 |
| `packages/ui/src/provider.tsx` | 浮层容器、主题作用域、系统减少动态、CSP nonce 和交互停用 | 替代应用鉴权或创建另一套焦点控制器 |
| `packages/ui/playground` | 直接引用正式组件的独立 Vite + React 工作台 | 发布到 `/admin/`、访问业务数据、保存预览偏好到用户存储 |
| `packages/ui/tests` | 算法、接口、生命周期与隔离浏览器场景 | 充当正式业务页面或可见产品内容 |
| `apps/admin/src` | 角色/世界书及运行管理页面、同源请求、路由、权限、草稿、保存和 409 冲突 | 复制通用控件、字体、设计目录或旧浮层控制器 |

包直接导出 TypeScript 源码及一个 CSS 入口，由消费方 Vite 编译；没有新增发布平台或预构建 JS 流程。React / React DOM 为 peer dependency，根 npm workspaces 与唯一 `package-lock.json` 管理四个包。包为私有包，当前不承诺仓库外发布。

Base UI 管理键盘、焦点、交互状态与无障碍基础；共享组件补齐外观和呈现生命周期。每项交互只有一个控制者，不能再套旧 Dialog、Esc、焦点或滚动锁控制器。复杂程度不是归属标准：通用表格属于共享包，世界书条目编辑器仍属于后台。

## 组件和工作台

| 类别 | 已导出能力 |
| --- | --- |
| 基础操作 | `Button`、`IconButton`、`Icon`、`Badge`、`Spinner` |
| 表单 | `Field`、`Input`、`Textarea`、`Checkbox`、`RadioGroup`、`Switch` |
| 选择 | `Select`、可搜索 `Combobox` |
| 导航和内容 | `Tabs`、`Accordion`、`Panel`、`PageHeader` |
| 浮层 | `Dialog`、`ConfirmDialog`、`Drawer`、`Menu`、`Popover`、`Tooltip` |
| 反馈 | `Toast`、`ErrorNotice`、`Empty`、`Skeleton` |
| 数据 | `Toolbar`、`DataTable`、`Pagination` 及受控排序/选择辅助函数 |
| 材质与作用域 | `Glass`、`AmbientBackground`、背景预设、`UiProvider`、`UiInteractionProvider` |

组件保留适用的受控属性、事件、`ref`、类名与 ARIA 接口；具体签名以导出类型及 [UI 包说明](../packages/ui/README.md) 为准。表格不请求接口，调用方持有查询、排序、分页和跨页选择。短字段默认不折行，长标题列显式 `wrap: true`；窄屏允许表格横向滚动。日期、富文本和虚拟表格不是本轮第一批能力。

工作台包括基础操作、表单输入、选择与切换、弹窗与菜单、状态与反馈、数据与筛选、组合场景七组。桌面侧栏导航，700px 及以下提供分类菜单。它覆盖长中文、禁用、加载、错误、空列表、可恢复保存失败、草稿取消、嵌套选择器、菜单打开弹窗及玻璃后长文。数据场景使用 23 条内存任务；背景、密度、长文、进一步减少动态和故障开关均只在当前页内存，刷新恢复，不写产品存储。

## 视觉与交互约定

Geist / Geist Mono 与中文系统回退字体统一来自共享资源。标题、正文、辅助说明、占位符、禁用及错误状态使用已有层级；菜单及展开选项采用共享深色样式，避免原生系统下拉破坏一致性。

| 表面用途 | 当前推荐参数及权威来源 |
| --- | --- |
| 导航与轻量控件 | 磨砂 2px、最大单轴折射 14px、边缘 20px、`#667585` 染色 24%；`NAVIGATION_PRESET` |
| 弹窗与抽屉 | 磨砂 2px、折射 17px、边缘 22px、`#0A121A` 染色 40%、内容衬底 61%、外遮罩 30%；`DIALOG_PRESET` |

材质、可读内容衬底、文字和遮罩分开管理。Dialog 玻璃宿主及带后代玻璃的祖先保持静止且不整体淡出；材质、内容和装饰独立同步退出。业务关闭立即发生，呈现阶段保留最后打开时的内容快照，退出期间停用交互。中途重开取消旧退出；权限失效立即移除敏感浮层。Select 自己拥有采样层且没有后代玻璃，可按自身结构淡出，不能机械套用所有玻璃同一规则。

长正文不逐行交错入场、不缩放或模糊，不以输入值、搜索词或保存版本触发重挂载。请求按照接口实际完成，不为了动画增加等待。忙碌按钮保持宽度。系统减少动态始终优先：Provider 的 `true` 只能进一步减少，`false` 或省略均跟随系统，不能强制绕过系统偏好。

## 迁移与清理

- 后台的 Button、Field、输入、选择、表格、分页、通知及浮层从 `@between/ui` 引入；角色、世界书及模型/运行管理继续调用现有管理员 HTTP 契约。
- 删除原 `apps/admin/src/ui.tsx`、`icons.tsx`、`skill.ts` 和 `apps/admin/public/design`，去掉重复原生控制器、旧 `surface-motion.js` 及未使用运行模块。后台只保留业务阅读/路由切换动画与业务布局。
- 图标依赖统一由 UI 包持有；通用样式只有一个入口，避免两套按钮、输入、表格或浮层规则叠加。旧组件别名和无效样式随迁移清除。
- `packages/ui/design-assets.json` 与校验脚本核对 21 个实际运行资源、11 个本地引用、字节 hash 和来源 hash；拒绝额外文件、缺失引用、符号链接和后台重复设计目录。校验是资源证据，不是视觉验收。
- 工作台、故障注入和生命周期 fixture 独立于后台入口。后台静态回归检查不发布 playground、QA 入口、测试资源和源码映射。

## 可复现命令

在仓库根目录使用 Node 24.x、npm 11.x。本次机器没有安装 Playwright 自带 Chromium；实际复验通过 `CHROMIUM_PATH` 使用已有官方 Google Chrome，无需修改源码或关闭浏览器 sandbox。其他环境若已安装兼容的 Playwright Chromium，可省略该变量。

```sh
npm ci
npm run check
CHROMIUM_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm run test:browser

# 共享组件工作台
npm run dev:ui
npm run build:ui-playground
npm run preview:ui
CHROMIUM_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm run test:ui:browser

# 后台真实 HTTP 的隔离预览
npm run build
BETWEEN_ADMIN_PREVIEW_PORT=0 npm run preview

# 依赖通知随当前安装平台重新生成
npm run licenses
```

工作台及预览只监听回环地址，使用终端输出的实际端口。预览会输出示例管理员口令，使用独立临时数据目录；关闭本次预览清理自有目录。不得将已有用户目录或运行凭据交给这些入口。工作台保存是页面内存模拟；后台预览保存走真实 HTTP API，但其数据、套餐替身和聊天模型仍为虚构/离线内容。

## 已修正的问题与反例

| 问题 / 影响 | 处理 | 复查证据类型 |
| --- | --- | --- |
| Portal 首次提交晚于动画启动，第一次开窗可能跳过进入 | 以 Popup 实际挂载启动呈现，不只观察业务 `open` | 生命周期、浏览器及最终完整开合录屏目视 |
| Combobox 关闭状态 Esc 清空已选项，或吞掉外层关闭 | 根据展开状态和事件原因保留选择，必要时允许外层传播；展开时只关闭当前层 | UI 9 组、实际嵌套操作 |
| 业务已关闭但退出未结束时背景可滚动 | 仅在短暂退出阶段阻止 wheel/touchmove，重开/销毁/结束清理；不另造第二套焦点或滚动锁 | 生命周期、浏览器滚动断言 |
| macOS 风格鼠标触发器未取得焦点，关闭无法正确回焦；菜单又可能抢离新弹窗 | 记录有效触发器，交给 Base UI 最终回焦，尊重已取得焦点的新层 | 菜单转弹窗及独立触发器浏览器回归 |
| Tooltip 存在视觉提示但触发器未关联描述 | 唯一 id 与 `aria-describedby` 合并，保留原描述 | 接口/语义检查及浏览器 |
| 严格 CSP 宿主下底层库所需样式缺少 nonce | Provider 接收服务端 nonce 并传给 Base UI CSPProvider，不扩大 CSP | 后台 CSP/网络回归及源码 |
| 工作台开关可能覆盖系统减少动态 | 系统偏好优先，本地只能进一步减少；关闭本地开关仍跟随系统 | 实际运行时动画时长非空采样与浏览器回归；不是 FPS 测试 |
| 忙碌文字和图标改变按钮宽度 | 使用 `loading` 契约保留原标签占位、禁用及 `aria-busy`；刷新按钮使用同一机制 | 组件检查与实际保存反馈 |
| 窄表把“米拉”这类短字段逐字折行 | 短字段不换行、表格横向滚动；长标题通过列配置显式换行 | 390px 目视发现、修改后重拍 08；响应式回归 |
| 替换旧表格结构后相邻筛选间距选择器失效 | 更新业务布局选择器至共享数据容器 | 源码与窄屏重拍 |
| RadioGroup 用 option value 拼描述 id，含空格 value 会被拆成多个 IDREF | 描述 id 与输入 id 使用相同编码，保留原业务 value；测试按实际 IDREF 验证说明关联 | 新增回归包含于 UI 31 项单测，最终根检查及浏览器全套通过 |

仅增加 `position: relative` 没有被证明消除了玻璃透射，不把该修改列成已解决视觉问题。文字层布局、材质层及阅读衬底仍需以最终截图和正常过渡判断。

录屏也暴露了两类验证工具反例：

1. 最初 CDP 捕获中有 10 帧出现半尺寸内容与深色区域。按原始 PTS 修复编码时间仍不能消除原始捕获像素伪影。旧录屏和 contact sheet 保留用于定位，不作为最终通过证据；对照普通截图、以原生尺寸重新捕获并实播后再判断，不能为捕获异常随意改玻璃配方。
2. 新 `ui-overlays` 短段在弹窗设为 `inert` 后，`getByRole` 已视其不可访问，脚本据此过早停止；尾帧仍有退出中的轮廓，不能证明关闭完成。保留该段并明确标“不完整”，改为等待实际 DOM 卸载再录回焦，补录 `ui-overlays-complete`。禁止添加空白尾帧或人工停顿伪造完整退出，也不能把 ARIA 不可访问当成实际 DOM 已卸载。
