## 技能与实现规则

实际使用仓库 `.agents/skills/ui-ux-pro-max/SKILL.md`、`references/pro-rules.md`，以及 `.agents/skills/ui-ux-self-check/SKILL.md`。

ProMax 查询 `content management dashboard dense` 返回 Data-Dense Dashboard 风格，也混入不适用的 Enterprise Gateway 页面模式；按用户目标排除营销模式，再查询 `data dense dashboard` 的 style 域。采用固定导航、较紧凑控件和直接呈现业务内容，未采用生成的浅色/Fira 建议。React 查询 `forms controlled state` 用于受控编辑与草稿状态。以上是本轮查询摘要，不冒充原始 stdout；旧 runs 只属于旧方案。

- 桌面侧栏 216px、顶部工具栏 56px、工作区边距 24px，主要控件高度 36px。800px 以下使用可关闭抽屉导航；600px 以下目录单列。
- 保留深蓝画布 `#080d1b`、内容面 `#131c32`、浮层 `#19243c`、正文 `#eef3ff`、次文 `#b0bdd4`、蓝紫/冷青动作与焦点；14px 内容卡圆角及细边框。取消球体、轨道、英文栏目号、营销标题、标语、指标装饰和重复介绍。
- 六模块固定入口：角色库、世界书、模型与提示词、会话与任务、用户与全局、素材与诊断。真实接口、并发版本保护、登录过期、取消/确认、用户隔离继续工作。
- 角色 11 个文本字段、世界书每个条目的正文都可完整阅读；目录搜索、跳转和键盘焦点可用。正文为 16px / 1.85 行高，限制每行宽度而不截断正文。列表简介用于定位，详情不使用摘要替代。
- 编辑抽屉最大 1040px；长字段可展开为最大 1120px / 60vh 文本编辑区。输入直接进入表单草稿，应用不等于保存，放弃可恢复展开前该字段值。保存仍需确认；刷新/离开沿用 dirty 防丢保护。
- 世界书常用条件直接编辑，深度、分组、扫描等剩余原始字段在扩展 JSON 中编辑，校验对象格式并禁止覆盖 UID/常用字段。`{}` 可清空扩展字段，空 entries 数组与旧单正文模式保持不同语义。
- 用户 `/api/state` 仅返回角色公开白名单，社区角色固定公开简介；不返回默认 Persona、描述/性格/场景、系统提示、来源原始字段或世界书。SSE done 仅返回回复/媒体/版本白名单，去掉编译后的提示字段；默认 Persona 仍由服务器注入。
