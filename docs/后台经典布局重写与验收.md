## 技能与实现规则

实际使用仓库 `.agents/skills/ui-ux-pro-max/SKILL.md`、`references/pro-rules.md`，以及 `.agents/skills/ui-ux-self-check/SKILL.md`。

ProMax 查询 `content management dashboard dense` 返回 Data-Dense Dashboard 风格，也混入不适用的 Enterprise Gateway 页面模式；按用户目标排除营销模式，再查询 `data dense dashboard` 的 style 域。采用固定导航、较紧凑控件和直接呈现业务内容，未采用生成的浅色/Fira 建议。React 查询 `forms controlled state` 用于受控编辑与草稿状态。以上是该轮查询摘要，不是原始 stdout。

- 桌面侧栏 216px、顶部工具栏 56px、工作区边距 24px，主要控件高度 36px。800px 以下使用可关闭抽屉导航；600px 以下目录单列。
- 保留深蓝画布 `#080d1b`、内容面 `#131c32`、浮层 `#19243c`、正文 `#eef3ff`、次文 `#b0bdd4`、蓝紫/冷青动作与焦点；14px 内容卡圆角及细边框。取消球体、轨道、英文栏目号、营销标题、标语、指标装饰和重复介绍。
- 六模块固定入口：角色库、世界书、模型与提示词、会话与任务、用户与全局、素材与诊断。真实接口、并发版本保护、登录过期、取消/确认、用户隔离继续工作。
- 角色 11 个文本字段、世界书每个条目的正文都可完整阅读；目录搜索、跳转和键盘焦点可用。正文为 16px / 1.85 行高，限制每行宽度而不截断正文。列表简介用于定位，详情不使用摘要替代。
- 编辑抽屉最大 1040px；长字段可展开为最大 1120px / 60vh 文本编辑区。输入直接进入表单草稿，应用不等于保存，放弃可恢复展开前该字段值。保存仍需确认；刷新/离开沿用 dirty 防丢保护。
- 世界书常用条件直接编辑，深度、分组、扫描等剩余原始字段在扩展 JSON 中编辑，校验对象格式并禁止覆盖 UID/常用字段。`{}` 可清空扩展字段，空 entries 数组与旧单正文模式保持不同语义。
- 用户 `/api/state` 仅返回角色公开白名单，社区角色固定公开简介；不返回默认 Persona、描述/性格/场景、系统提示、来源原始字段或世界书。SSE done 仅返回回复/媒体/版本白名单，去掉编译后的提示字段；默认 Persona 仍由服务器注入。

## 七项自查与修复

历史结论：该次离线管理流程及所检查尺寸范围内通过；当时未验证真实模型表现、真实凭据授权与跨环境接收。

| 自查项 | 结果及实际证据 |
| --- | --- |
| 01 核心任务闭环 | 浏览器通过导入→阅读全部字段/条目→编辑→确认保存→刷新；创建/移除角色与世界书、绑定清理、模型/预设配置、用户停用恢复、删除虚构会话均使用真实本机接口。另用可见 Chrome 在375px完成展开编辑→应用→保存→确认→刷新阅读，追加文本仍在。 |
| 02 信息层级 | 删除红框中精选社区介绍与各页宣传区；经典导航和工具栏固定；素材四卡直接出现在桌面首屏，重复封装说明合并到来源折叠区。 |
| 03 状态与异常 | 覆盖加载、登录失败、过期、网络错误重试、409并发冲突保留草稿、搜索空结果、无用户/会话/世界书、保存失败、任务停止与取消。原来过大的运行任务空态已改为紧凑文本。 |

| 06 交互可控性 | 保存、移除、暂停和删除有确认；展开字段放弃有回滚确认；键盘开关、Esc、焦点返回、跳过导航、移动抽屉验证。修复展开编辑未触发 dirty 导致刷新丢稿的问题，新增卸载保护断言。取消字段后 dirty 保守保留，会有一次多余离开确认。 |

本轮主要问题和修复顺序：

1. P1：旧用户状态与 SSE 返回提示字段 → 改公开白名单并补隐私回归；服务端默认设定注入仍通过测试。
2. P1：展开文本只在局部草稿，未进入离开保护 → 改为表单受控值和字段回滚，实际应用/取消/防丢回归通过。
3. P2：桌面与手机字数与展开按钮重叠 → 独立工具栏，查看新截图确认分离。
4. P2：旧营销布局、重复说明、巨大空态和卡片动作错位 → 经典侧栏、紧凑标题/工具区、说明去重、空态压缩、底部动作对齐，逐页复看。
5. P2：世界书扩展只能查看不能编辑 → JSON对象编辑，非法输入拦截，新增/清空与未知字段保存回归通过。
