# 图标库选型与视觉修正

Between 管理后台统一采用 **Lucide React**。选型依据是官方 React 接口、线条规格和实际业务语义覆盖；不做流行度排名。本次资料核验日期为 **2026-10-16**。

## 图标库比较

| 图标库 | React 包与核验版本 | 许可 | 按需引入、线条与后台适配 |
| --- | --- | --- | --- |
| **Lucide（采用）** | `lucide-react@1.58.0` | ISC；完整许可同时包含继承自 Feather 的 MIT 通知 | 具名静态导入、tree-shaking、TypeScript；24 网格，默认 2px，可用 `strokeWidth` 统一调整。八项业务菜单均有直接对应图标，适合此次线框风格。[^lucide] |
| Tabler Icons | `@tabler/icons-react@3.49.0` | MIT | ESM 按组件引入、tree-shaking、TypeScript；24 网格，默认 `size=24`、`stroke=2`。后台与专业业务图标覆盖充分，也是可用方案。[^tabler] |
| Phosphor | `@phosphor-icons/react@2.1.10` | MIT | 具名导入、tree-shaking、TypeScript；256 网格，可输出 24px，提供 thin、light、regular、bold、fill、duotone。适合需要多字重或双色的界面，使用时需统一 weight。[^phosphor] |
| Heroicons | `@heroicons/react@2.2.0` | MIT | 按 `/24/outline` 等样式子路径引入，支持 ESM 与 TypeScript；24px outline 的原始线宽为 1.5。常规后台覆盖足够，角色设定类语义需要使用通用符号。[^heroicons] |

四个版本均通过 npm registry 的 `latest` 元数据实查。此次 Lucide 的 GitHub `releases/latest` 页面返回 1.57.0，与 registry 的 1.58.0 不一致；安装基线采用 registry 精确版本，仓库 main 中的版本占位值不作为发布版本依据。[^versions]

## 安装与许可保留

`apps/admin/package.json` 与 `package-lock.json` 已将 `lucide-react` 固定为 **`1.58.0`**；本地实际安装包版本也是 1.58.0。

完整安装包 `LICENSE` 已收录至 [第三方许可通知](../licenses/THIRD-PARTY-NOTICES.txt)，其中保留 ISC 正文，以及 Feather 图标的 MIT 正文与 Cole Bemis 版权通知。此次逐字包含检查确认，通知文件收录了安装包的完整许可内容；不能只保留一个 `ISC` 标签。依赖元数据记录在 [dependency-manifest.json](../licenses/dependency-manifest.json)。

## 本轮视觉规范

| 项目 | 统一规则 |
| --- | --- |
| 网格与显示尺寸 | SVG 使用统一 24×24 网格；默认显示 18px，辅助图标按场景使用 14–17px，空状态使用 26px。 |
| 线条与颜色 | 统一 `strokeWidth={1.75}`；图标继承文字颜色，选中状态由颜色与背景表达。 |
| 引入方式 | 固定 20 个实际使用的静态组件，逐个具名导入；删除没有调用的 back、play/pause 项，不使用动态全库导入。 |
| 外观入口 | 使用 `Palette`；避免不规则手绘 gear 造成轮廓、笔画和视觉重心不一致。 |
| 品牌标记与管理员头像 | 保留现有字母与锁的语义，使用定向的内部顶部高光；高光收在自身轮廓内，不增加向外扩散的光晕。 |
| 可识别性 | 图标旁保留菜单文字；角色卡与真实用户管理使用不同图标，避免语义混淆。 |

上述尺寸、线宽与高光规则属于本轮设计及实现约束。页面观感、裁切、对齐和操作表现应由下面的实际验收记录证明。

| 菜单 | Lucide 组件 | 语义 |
| --- | --- | --- |
| 角色卡 | `ContactRound` | 人物档案 |
| 世界书 | `BookOpen` | 背景知识与设定条目 |
| 素材 | `Images` | 图片及媒体集合 |
| 模型 | `Cpu` | 模型与计算配置 |
| 会话 | `MessagesSquare` | 多条对话记录 |
| 用户 | `UsersRound` | 真实账号与成员 |
| 诊断 | `Activity` | 运行状态及诊断 |
| 外观设置 | `Palette` | 主题和颜色 |

以上八个名称均已逐项核对官方图标目录。[^mapping]

## 已发现并修正的反例

首次目视检查搜索空状态时，发现通用 Empty 原先把素材图标写死；换成 Images 后，角色搜索无结果也出现图片图标，语义不合适。现改为可指定 `icon` 的组件：搜索无结果默认 Search，无会话用 MessagesSquare，无用户用 UsersRound，选择角色用 ContactRound，世界书和空条目用 BookOpen。图标接入时不能只看 SVG 清晰，还应在真实空状态中核对其含义。

### 七项自查与回归

| `ui-ux-self-check` 检查项 | 本轮结论与依据 |
| --- | --- |
| 任务闭环 | 安装、替换、搜索恢复、导航、外观弹窗开关实际可操作；没有仅下载未接入。 |
| 信息层级 | 图标辅助菜单文字，18px / 1.75 线宽没有盖过标题和正文；品牌与头像没有外溢高光。 |
| 状态与异常 | 手工看常态、悬停、选中、键盘焦点和无结果；后台浏览器回归覆盖加载、失败、禁用、401、409 与草稿恢复。 |
| 真实数据与接口 | 临时虚构内容明确标注，使用实际应用 API；社区素材保留原有归因，未把合成模型写成真实推理。 |
| 视觉一致性 | 统一 Lucide 语义表、尺寸、线宽与 currentColor；删除手绘不规则图标及静默回退为设置图标的逻辑。 |
