## 结构决策与实际改动

- `apps/admin` 保留当前 React/TypeScript/Umi Max/Ant Design Pro/Tailwind 后台，页面仍在其 `src/pages`。修正 workspace hoist 后的 CSP 补丁解析与测试引用，不重做 UI。
- `apps/server` 承载原引擎内应用的聊天页面、HTTP/API、鉴权、角色/世界书、模型/套餐兼容服务和启动器；通过包名依赖角色引擎。后台构建路径指向同级 `apps/admin/dist`。
- `packages/role-engine` 保留原角色编排、会话/事务、媒体、语音、vendor 与固定 oracle。原酒馆配置仅抽出实际使用的三个部分到 `defaults.json`，值保持相同；演示媒体归应用 fixture，不再读取研究目录。
- 统一 npm workspaces、单根 `package-lock.json`、Node 24.x/npm 11.x。根开发、构建、检查、测试、启动和 CI 全部指向当前产品。保留原有效依赖版本，新增声明原已使用的 `@rc-component/util@1.12.0`；Acorn 按原引擎精确 8.16.0 统一，未升级模型/界面技术栈。
- 删除 Electron desktop、core/contracts/host-qwen/mcp-server、旧产品 Skills/角色/评测/补丁/上游工具和配置、旧 pnpm 锁与入口。删除原酒馆完整 `public/src/default/server.js` 应用树和一次性裁剪研究工具；固定 oracle、有效源码提取工具、社区卡和许可已归入实际拥有者。旧后台 DOM 测试与被否定 Orbit 设计/历史交接证据清除，不保留双轨空壳。
- 保留根/服务/引擎 AGPL、后台模板 MIT、社区 CC BY 4.0、灵光原模块来源说明和 vendor provenance。16 个关键 vendor/社区/灵光文件与基线逐字节一致；四张社区卡 hash 和必要默认值独立复核通过。依赖通知改为按当前锁与安装平台收集，不用废弃 Electron 清单冒充当前清单。
- 根 CLI 冒烟发现 npm 与进程组可能重复送达停止信号，导致清理前退出并遗留引擎锁。CLI 现保持信号处理器并共享一次关闭 Promise；实际根 `npm start` 的 SIGTERM/锁释放回归通过。
