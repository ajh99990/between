## 怎样保持这份索引有效

维护规则统一写在 [AGENTS.md 的“文档维护”](../AGENTS.md)。新增主题先找已有文档；修改决定同时修正冲突表述；合并和删除同时修入链。无继续比较价值的过时流程直接删除，必要历史用固定 Git 版本追溯，不另建一套归档目录。
