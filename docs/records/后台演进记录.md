## 保留的具体反例

常规验收要求已进入 [AGENTS.md](../../AGENTS.md)，这里保留容易在后续重构中重犯的具体因果。

| 失败情形 | 已采用的修正或判断 |
| --- | --- |
| 根 `npm start` 收到重复 SIGTERM，清理结束前退出并遗留引擎锁 | 共享关闭 Promise；用真实 CLI 停止与锁释放回归验证，不能靠手动删锁掩盖问题 |
| 早期用户 API/SSE 泄露内部提示字段；展开编辑未进入草稿保护 | 修正出站字段边界与草稿跟踪；用户可见内容和内部上下文不能共用不加筛选的对象 |
| 401 后只隐藏正文，portal 与焦点锁仍在 | 权限失效立即停用浮层与交互；保存草稿不等于保留可访问私密正文 |
| 首次 GET 503 后迫使管理员重新登录 | 已有有效 cookie 时提供只读重试，不为读取失败重复登录 |
| 多个测试场景共享服务，第六次登录触发限流 | 隔离测试服务，不降低产品登录保护 |
| 关闭弹窗先清空业务对象，退出只剩空玻璃框 | 退出阶段保留呈现快照并同步收掉材质、内容、边框；重开取消旧退出 |
| `inert` 使 `getByRole` 不再可访问，录屏过早结束 | 不可访问不等于 DOM 已卸载；等待真实退出完成和回焦再结束录制，不能补空白尾帧伪造完成 |
| CDP 捕获出现半幅图像、菜单硬边等伪影 | 先对照普通截图与原生尺寸捕获，不据单一捕获异常改变玻璃配方 |
| 搜索无结果统一使用图片图标 | 按语义选择 Search、人物、世界书或会话图标，核对空态而非只看 SVG |
| 短人名在窄表中逐字换行；换容器后筛选间距失效 | 短字段不换行、表格横向滚动，长标题按列允许换行；在真实窄屏重新看像素 |
| 选项 value 含空格，被拼成多个描述 IDREF | 描述 ID 独立编码，业务 value 不变；逐项检查描述关联 |
| Tooltip 有文字却未关联触发器，或严格 CSP 下库样式失败 | 合并 `aria-describedby`、沿共享 Provider 传入 nonce；不放宽 CSP 或增加第二套控制器 |
| 玻璃透明度规则被泛化为“所有浮层都不能淡出” | Dialog/Drawer 的宿主与后代玻璃祖先保持静止；自身采样且无后代玻璃的 Select/Combobox 可按现有结构整块淡出 |
