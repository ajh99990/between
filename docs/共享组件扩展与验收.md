# 共享组件扩展与验收

本批在既有 `@between/ui` 上扩充 13 个通用组件，并增强原有 DataTable。正式后台与独立组件工作台共用源码、字体、材质、图标与动画。角色卡、世界书、模型设置、会话、用户与诊断页使用真实接口；演示内容只在独立工作台和显式启动的临时预览中。

## 实现范围

| 能力 | 共享组件 | 实际后台落点 |
| --- | --- | --- |
| 阅读与定位 | DocumentReader、HighlightText | 角色 11 字段、关联世界书、来源归因；条目世界书完整正文、触发配置与原始字段 |
| 可调工作区 | SplitPane、CollectionList | 角色库、世界书库；鼠标和键盘调宽、窄容器展开入口 |
| 长文编辑 | LongTextEditor | 角色字段、世界书正文、全局历史后指令；保持同一 textarea、选区与原始换行 |
| 多项与关键词 | MultiSelect、TagInput | 世界书关联、角色关键词、主次触发词；支持完整词组与点击保存前提交输入 |
| 精确参数 | NumberField、Slider | 模型预算、回复上限、温度、条目概率和排序；Slider 仅用于工作台，后台精确值不强加滑块 |
| 结构化内容 | JSONViewer、JSONEditor、DiffViewer | 原始元数据、全部触发字段、扩展编辑、旧草稿和冲突版本比较 |
| 表格与筛选 | 原有 DataTable、ColumnVisibilityControl、FilterBar | 任务、会话、用户、操作记录；受控列宽、显隐、固定表头/操作、组合条件移除和清空 |

公共出口和 CSS 入口均在 `packages/ui`，高级业务能力仍留在 `apps/admin`。独立工作台扩为 11 组，新增四组为“多选与参数”“阅读与编辑”“JSON 与差异”“高级表格”。

## 排查和修正

1. **分栏看得到但拖不了。** Tailwind preflight 把 hr 高度重置为 0。分隔线改为实际伸满网格的非零高度，记录 pointer 起点与初始宽度，按增量调宽；浏览器验证真实拖动 32px 恰好增加 32px。
2. **长文定位后搜索控件消失。** 搜索栏在真实阅读滚动容器内常驻，使用密集阅读衬底；目录正常滚动，避免堆叠多行固定栏挤占阅读空间。
3. **输入了关键词却需要再次点击保存。** 不能依赖 effect 延迟通知 pending，也不能在失焦提交后抢回焦点。同步通知临时输入和提交清空；合法失焦提交后，一次点击即可保存。
4. **重复词输入在切换后丢失。** 控件拒绝重复词时必须保留输入。业务页面用即时 pending 引用阻止非法草稿切字段、切条目、新增条目或进入版本比较；给出恢复提示。已确认删除或放弃编辑才丢弃相应草稿。
5. **保存期间继续输入导致晚输入消失。** 角色保存时禁用整个编辑区和文档选择，保留内容；结束后再恢复。真实 PUT 被暂挂的浏览器回归验证了禁用状态。
6. **格式化无损，但业务 JSON.parse 有损。** 通用格式化只增减空白，保留数值与转义字面值。业务提交另行拒绝重复键、超出安全范围、溢出/下溢及有效位丢失；不改原始草稿，不把错误伪装成保存成功。
7. **区域名与文本框名重叠。** JSON 编辑区域命名与其 textarea 区分，字段仍可按其业务标签直接定位。过滤恢复操作按明确筛选区域定位，避免同名动作歧义。
8. **自动化说查找通过，实际选区仍在视口外。** 在真实浏览器中确认了 `setSelectionRange` 未使 textarea 内部滚动。按实际字体和换行同步测量命中位置，显式滚动内部及可滚动祖先；隐藏排版镜像在本次同步操作结束前移除。最终实际页面的末尾命中为 1928–1932，内部 scrollTop 为 1800，蓝色选区可见，展开/收起不重建 textarea。
9. **聚焦后顶栏上移、底部出现黑区。** 根容器的 `overflow: hidden` 仍可被聚焦和 `scrollIntoView` 隐式滚动。桌面外壳改用 `clip`，内部 main/阅读区继续独立滚动；真实页面确认外壳 scrollTop 为 0、顶栏仍位于 0。不用截图专用 CSS 遮掩产品问题。
10. **键盘能调列宽，鼠标却选中了相邻表头文字。** 调宽柄向外伸入相邻固定表头的命中范围。把完整命中区收进所属表头；实际鼠标拖动使列宽从 300 增到 324，而不只检查 separator 存在或键盘生效。

具体 API 和使用边界见 [共享包说明](../packages/ui/README.md) 与 [视觉规范](../design-system/between-admin/MASTER.md)。
