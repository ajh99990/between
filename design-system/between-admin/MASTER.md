# Between 管理员玻璃工作台设计规范

本文件约束当前 `apps/admin` 及其共享 `@between/ui`，技术栈为 React、TypeScript、Tailwind CSS 与 Vite。`packages/ui` 是通用组件、字体、材质、程序背景、图标和浮层动画的唯一来源：Base UI 提供交互基础，共享 React 组件提供当前视觉。底层通用资源自包含，不依赖其他业务仓库，也不恢复旧后台模板、原生控件控制器或兼容入口。设计依据见 [管理员内容编辑调研](../../docs/管理员内容编辑调研.md)，现行使用入口见 [UI 包说明](../../packages/ui/README.md)，本批当前验收见 [共享组件扩展与验收](../../docs/共享组件扩展与验收.md)。[早期后台验收](../../docs/后台玻璃工作台重写与验收.md) 只对应原版本，不能证明当前扩展已通过；规范本身不等于验收通过。

## 任务与内容结构

固定七个工作区：角色库、世界书、社区素材、模型与提示词、会话与任务、用户与全局、诊断。导航名称和入口必须对应真实接口能力，不用营销横幅、空洞指标、重复说明或装饰卡片填满页面。

角色与世界书采用“选择目录 → 完整阅读 → 明确编辑 → 服务器确认保存”的工作流程。角色全部 11 个正文字段保留原文、换行与模板字符，并提供搜索、字段目录、关联世界书和来源归因。世界书分库与条目两级选择，全文与触发条件同时可读；简单世界书与 `entries: []` 不混淆。条目 UID、来源、未知字段、空值继承及未编辑配置不能因为表单未展示而丢失。原始 HTML 作为纯文本显示，不执行内容或自动加载外部资源。

正文阅读和编辑需要足够宽高，不把完整档案塞进狭窄弹窗或机械拆为小输入框。表格用于会话、用户和审计等结构化记录；状态、负责人、日期和操作避免被挤成单字换行，横向滚动限制在表格自身区域。空、加载、错误和禁用应说明当前状态及可行的恢复动作，不能只有颜色或动画。

阅读工作区复用 `DocumentReader`、`SplitPane`、`CollectionList`、`LongTextEditor`：目录和正文纯文本查找、可调分栏、稳定 textarea 与展开编辑由共享包实现；角色/条目身份、模板含义、未保存确认和新会话生效规则仍由后台持有。正文输入、搜索词、保存版本不能触发重新挂载。窄屏列表可收起，不能把目录入口放进不可见的横向区域。

固定选项关联使用 `MultiSelect`，自由关键词使用 `TagInput`；不把空格/逗号擅自当成分隔协议。`NumberField` 表达可空与精确数字，`Slider` 用于适合连续调整的单值并显示精确值。`JSONViewer` / `JSONEditor` 保留原文与错误定位，`DiffViewer` 对照文本；这些组件不接业务 API、不生成保存状态、不决定触发条件、不自动合并版本。连同 `FilterBar` / `ColumnVisibilityControl`，本批扩展 13 个主要通用组件，完整接口以 UI 包说明和类型声明为准。

## 字体、层级和布局

使用随包 Geist / Geist Mono 公共字体及平台中文回退，不加载远程字体。中文实际字体由平台提供，不能把 CSS 字体列表当作字体已生效的证据。字段标签和常规输入采用 **14px / 22px、400 字重**；阅读正文采用 **15px / 1.85、400 字重**。标题、正文、辅助说明、时间/元数据和禁用文字分别使用通用文字 Token，不将整个前景容器降透明来制造层级。

字体、Token、通用控件和材质样式由 `packages/ui/src/styles`、`components` 与 `materials` 管理。应用布局与业务密度由 `apps/admin/src/styles.css` 装配：桌面侧栏配工作区，角色/书库目录与阅读主体并列；窄屏使用可关闭导航、横向内容选择与单列阅读。断点应按真实文本与控件容纳情况检验，不能仅凭媒体查询存在就宣称响应式完成。正文限制舒适行宽但不截断，长 URL、ID 和 JSON 可折行或在自身容器滚动。

主要操作、次要操作、危险操作和禁用状态保持一致。导航悬停具有半透明高亮背景，当前项有明确文字和背景反馈；按钮高光、焦点边缘与玻璃边缘必须可见，但不能照亮整块长文。原生系统下拉菜单不能冒充已设计的深色展开菜单。

## 图标与身份标记

只使用本地锁定的 Lucide React，`packages/ui/src/icons.tsx` 统一语义映射及静态导入，禁止重新手写不规则齿轮、混用多库或运行时加载整库。使用 24×24 viewBox、1.75 线宽、圆端点；默认 18px，辅助图标 14–17px，空状态 26px。角色档案与用户管理分别使用 ContactRound / UsersRound；外观入口用 Palette，反馈错误用 CircleAlert。空状态由 `Empty.icon` 明确指定业务语义，搜索无结果默认 Search；禁止把所有角色、用户、会话空状态都套用素材图片图标。图标继承文字色，SVG 不承担按钮的可访问名称，不使用全局滤镜或外发光。

品牌字母是应用身份标记，管理员锁代表当前鉴权身份，二者不伪装成可点击动作。小型标记保留定向内顶高光和弱蓝灰轮廓，避免整圈同亮描边、深色粗外环或向外泛白；文字与 SVG 不模糊。导航及操作图标不得逐个套玻璃球底座。视觉验收必须同时看亮/暗背景下的常态、悬停与键盘焦点，不能仅检查 SVG 已渲染。具体选型、反例和验证见 [图标库选型与视觉修正](../../docs/图标库选型与视觉修正.md)。

## 玻璃与背景

导航及轻量玻璃控件保留推荐配方：分区融合，磨砂 **2px**、最大单轴折射 **14px**、边缘宽度 **20px**、染色 **#667585**、底色不透明度 **24%**。高亮背景和折射边缘是独立效果，不能只用平面半透明颜色或边框替代。按钮和数据行仍须按角色选择材质，不要求每个单元格都开位移滤镜。

弹窗采用独立的 `DIALOG_PRESET`：磨砂 **2px**、折射 **17px**、边缘 **22px**、染色 **#0A121A / 40%**、内容衬底 **61%**、外遮罩 **30%**。光学层、内容衬底和外遮罩互相独立；文字层不参与模糊和位移。不能把导航参数直接套到大面积表单弹窗，造成背后字穿透、正文难读。长文本阅读主体应有稳定深色衬底，不为了玻璃效果牺牲辨读。

全应用共用单张抽象程序背景，默认静止，外观设置可切换 **8 个预设**并选择正常速度动效。背景应低对比、非具象、有层次；动态开启后在正常速度下可辨认运动，同时玻璃后仍可读。不要每个卡片单独生成背景、使用清晰具象图形或用过强动效抢夺注意。遵守 `prefers-reduced-motion` 并释放 Canvas、事件、滤镜和动画生命周期资源。

`npm run dev:ui` 调试正式源码的 playground，`npm run build:ui-playground` 独立构建，`npm run test:ui:browser` 构建并执行 UI 浏览器回归。工作台可保留明确的测试数据、模拟延迟与故障开关，但不得随后台发布；真实页面验收不能被工作台通过替代。旧 `apps/admin/src/ui.tsx`、`src/skill.ts`、`public/design` 与 `?qa=1` 探针不再作为当前组件或验证入口。

工作台当前有 11 组：基础操作、表单输入、选择与切换、弹窗与菜单、状态与反馈、数据与筛选、多选与参数、阅读与编辑、JSON 与差异、高级表格、组合场景。新增组件直接使用正式源码和材质；阅读、JSON 和高级表格各自提供有意义的测试数据与状态，不能复制工作台的虚构数据到日常管理员页面。

`DataTable` 与 `Pagination` 继续由宿主持有排序、分页和跨页选择状态；表格增加 CSS px 列宽、指针/键盘调整、列显隐、固定起/末列及固定表头。列宽回调缺失时不显示假拖拽手柄；必需/固定列和至少一列数据不可隐藏。`FilterBar` 只装配表单、结果数和筛选 chips，筛选生效、清空、分页重置、选择集合和接口请求由页面处理。固定列需要稳定深色衬底，防止横滚内容穿透；不为每个单元格叠加玻璃。

## 保存、权限与异常恢复

保存使用实际同源 API，等待服务器确认后才报告成功。角色、世界书和提示预设作用于新会话，既有会话快照不改写；模型配置保存和真实推理成功分别表达。API 不支持的上传、导出、聊天正文查看、密钥编辑和运行诊断不做伪功能。

配置编辑基于打开时版本。409 保留草稿与对照信息，不静默覆盖；同一本世界书被他人修改时不能自动合并未知字段。扩展 JSON 是完整的附加字段对象，删除键意味着明确删除，不能递归合并回旧值。保存成功后刷新失败应说明已提交，避免重复写入；忙碌状态防重复操作，失败不清空用户输入。

JSON 的语法合法、格式化原文无损和业务序列化可保存必须分别判断。格式化不得以 `JSON.parse → stringify` 改写数字字面量；宿主接口如仍使用 JS 对象，保存前必须拒绝重复键、超安全整数、非有限数或其他不能无损表达的内容，保留原文及可定位错误，不把无损展示误当成无损写回承诺。

关闭、切换、离开、刷新及登录失效都需保护未保存内容。删除、禁用、暂停和断开连接在确认中解释真实作用范围。鉴权由服务端 Cookie、Origin 和 CSRF 落实；管理员私有角色正文、世界书、内部提示与诊断不进入普通用户状态、聊天消息、SSE 或 TTS。敏感密钥不可读取和回显，开发验证工具不得导出业务正文或表单值。

自由词组的未提交输入也属于草稿。`TagInput.onDraftChange` 同步更新业务 pending ref，使“未按 Enter，直接点保存/切字段”的同一事件周期可正确判断；合法 blur 提交后可继续操作，重复等无效输入不得通过卸载清空。保存请求期间禁用角色输入、字段和目标切换，防止在请求快照之后又产生未纳入保存的新文字。

## 扩展组件的具体反例

| 错误实现 | 后果与约束 |
| --- | --- |
| 使用 `<hr>` 分隔条却遗漏 Tailwind preflight 的零高度 | DOM/ARIA 正确仍可能拖不了；明确非零指针区域并实际拖动、键盘调整 |
| 只靠 `setDraft` 后的 effect 通知 pending | blur 与紧接的点击读到旧值；同步回报输入及提交结果，不能靠延迟保存掩盖 |
| blur 提交完成后无条件回焦输入 | Tab/点击离开被拦截；blur 提交不得抢焦，其他提交方式按需继续编辑 |
| 重复词组被拒绝后继续切字段/条目、卸载输入 | 非法原稿丢失；调用方 pending ref guard 保留当前编辑和改正/取消入口 |
| 保存期间只禁保存按钮，角色输入仍可修改 | 响应覆盖请求发出后的新输入；锁定相关编辑/切换，失败保留草稿 |
| 无损 JSON 格式化后直接按 JS 对象保存 | 数字精度、溢出或重复键仍可能丢数据；明确区分展示与保存契约并拒绝不安全输入 |
| 长文查找仅 `setSelectionRange`，未确认命中可见 | 原生选区不保证内部滚动到命中；同步当前字体/宽度/换行规则测量排版镜像，显式调整内部滚动并保证祖先可见，测完立即移除临时镜像，保留原 DOM 和选区 |
| 桌面应用根 `overflow: hidden` 被焦点或 `scrollIntoView` 隐式滚动 | 侧栏/顶栏移位、底部黑区；桌面根使用 `clip`，main / reader 内部滚动，连续查找/切换/回焦后复查，禁止截图 CSS 遮掩 |
| 列宽手柄伸入相邻 sticky 表头命中区 | DOM/键盘正常却鼠标拖不了或改错列；限制所属列内的命中区域，用真实鼠标拖动已知距离并核对精确宽度增量，同时验证固定列与横滚边界 |

反例是后续回归要求，不能将修正规则本身当作已完成的视觉证据；本批最终覆盖、命令、实际截图与未测边界以当前验收报告为准。

## 端到端图验

验收使用临时虚构数据和随机回环服务，覆盖七个工作区、角色与世界书长文本、完整触发配置、搜索定位、表格/筛选、深色展开菜单、弹窗、未保存提示及删除确认。至少检查桌面、平板和手机常见尺寸，包含长中文、长 token、多条目、空结果、加载、请求失败、401、409 和禁用状态；验证键盘焦点、Escape、Tab 范围、减少动态效果和整页横向溢出。

先做真实浏览器操作，再截取目标页面并亲自查看像素：检查文字实际强弱、中文字体、玻璃中心与折射边缘、悬停/当前项高亮、展开菜单和长文可读性。发现问题要修改、重新截图、重新观察，并按 `ui-ux-self-check` 七项清单记录证据。静态检查、构建、DOM 断言和截图文件生成不能单独作为视觉验收通过依据。

证据需区分真实接口、隔离响应模拟、合成模型与未覆盖能力，保存代码版本、视口、执行命令和实际修正。UI 自动化证据位于忽略目录 `artifacts/browser/ui`，业务回归位于 `artifacts/browser/admin`；人工视觉证据同样不提交用户数据。每次组件迁移均须重新验收当前构建，不把旧界面报告的截图、数字或“通过”结论套到新实现。结束后恢复测试设置，并从普通业务入口复验，精确回收本次自有临时数据、模拟接线与故障覆盖，保留用户记录、草稿和回归 fixture。
