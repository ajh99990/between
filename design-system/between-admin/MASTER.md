# Between 管理端设计系统

## 用户任务与范围
管理员以内容为中心：浏览角色 → 完整阅读设定与绑定世界书 → 编辑明确字段 → 确认影响新会话 → 保存并重新读取。模型、用户、任务操作独立分区，不将用户聊天混入管理员配置面板。

## 技能执行与适配
使用 UI UX Pro Max 官方固定版本 7246805992a42b7bba37d4cac83b01416f0c6c44，完整读取 SKILL.md、quick-reference.md、pro-rules.md。设计系统查询 `content management dashboard` 错配教育营销页；仅重试一次 `enterprise admin dashboard`，返回运维落地页/玻璃效果，仍非本产品匹配。因此不持久化其未经验证的设计输出；以下为基于技能通用规则、现有 Pro 模板及实际任务形成的明确 fallback，不宣称数据库直接生成匹配方案。已查询 React 表单状态、Web 长文本 wrapping 与 Tailwind；截断建议仅用于列表摘要，全文视图不得截断。

## 框架与布局
完整 Ant Design Pro + React + TypeScript + Umi Max，保留 layout/model/initialState/access/request/locale 插件。Ant Design 控件负责表单、确认、导航和状态；Tailwind 负责页面布局及阅读排版，不开启 Preflight。不引入 Vite 或另一套 UI 框架。
桌面固定侧栏 224px，正文工作区自适应；详情页为可搜索目录 + 正文。小屏目录折叠，正文优先，表格自身横向滚动不带动整页。编辑抽屉保留取消/保存动作和未保存提示。

## 视觉与排版
采用既有深绿导航、白色内容表面、浅中性背景，色彩通过语义 token 管理。主色 #316a5b，正文 #20322b，次要正文 #53655e（需对真实背景检查），错误使用 Ant Design danger。取消“空气感”作为要求，不为装饰增加空白、玻璃、渐变或动效。
中文系统字体，无远程字体；正文 16px/1.8，标题 24–28px，元数据 12–14px。长正文桌面限宽约 76ch；用户内容 pre-wrap、overflow-wrap:anywhere，不对普通正文 break-all。统一 Ant Design 图标；角色自身 icon 字段为内容，可保留但不作为系统导航图标。

## 交互与异常
角色/世界书每个字段与条目全文可读、搜索、目录跳转，完整参数可展开；阅读与编辑分开。保存确认说明生效范围，保存失败保留草稿，版本冲突不覆盖服务端；保存后刷新失败提示不要重复提交。取消脏编辑需确认，刷新/关闭页面保护草稿。
空数据给具体恢复动作；异步按钮防重复提交；401 返回登录；权限/网络错误可恢复。危险操作明确确认。管理员不能因 UI 隐藏替代 API 身份和 CSRF 校验。

## 验收
实际浏览器验证桌面 1440/1024、平板 768、手机 375，长中文、长 token、多标签、搜索无结果、表单失败、保存刷新、取消及版本冲突。检查焦点可见、键盘操作、缩放、reduced-motion 和无横向整页溢出。使用许可社区素材与构造边界数据，不读取真实用户内容。Self Check 七维逐项记录实际观察/代码推断/待验证，不以类型通过代替视觉验收。
